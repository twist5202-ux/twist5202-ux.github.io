Install n8n

Pilih salah satu cara. Yang paling gampang: n8n Cloud.

Cara A — n8n Cloud (paling gampang, ada free trial)

  1. Buka n8n.io di browser
  2. Klik tombol "Start free trial"
  3. Daftar pakai email lo
  4. Pilih region Singapore (paling deket)
  5. Selesai — n8n langsung bisa dipakai

Cara B — Install di VPS sendiri (paling murah, jalan 24 jam)

Kalau lo punya server/VPS, jalankan perintah ini:

docker run -d --restart unless-stopped \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n

Lalu buka http://IP-SERVER-LO:5678 di browser.

Cara C — Install di komputer lo (gratis, tapi mati kalau PC mati)

Jalankan perintah ini di komputer lo:

npx n8n

Lalu buka http://localhost:5678

Tampilan editor n8n — kotak = node, garis = alur data

Connect Google Sheets ke n8n

Sekali setup, dipakai semua template. n8n butuh izin buat baca/tulis spreadsheet lo.

  1. Di n8n, klik ikon kunci (Credential) di panel kiri
  2. Klik Add Credential
  3. Cari dan pilih Google Sheets
  4. Klik Sign in with Google
  5. Pilih akun Gmail lo
  6. Klik Allow / Izinkan akses
  7. Klik Save
Alur connect Google Sheets — sekali setup, dipakai semua template
Tips: Credential ini cuma perlu sekali. Semua template bisa pakai credential yang sama. Kalau nanti ada node Google Sheets yang minta pilih credential, tinggal pilih dari dropdown.

Cara daftar & ambil token (contoh: Wablas)

  1. Buka wablas.com → klik Daftar
  2. Verifikasi email lo
  3. Klik Add Device / Tambah Perangkat
  4. Buka WhatsApp di HP → Perangkat Tertaut → Tautkan Perangkat
  5. Scan QR yang muncul di layar
  6. Setelah nyambung, buka menu Device
  7. Copy Token — simpan baik-baik
  8. Top up saldo (mulai Rp 50.000)
Scan QR pakai WhatsApp HP → device nyambung → copy token
Penting: Token itu seperti password. Jangan kasih ke orang lain selain yang setup n8n lo. Kalau token bocor, orang lain bisa kirim WhatsApp pakai nomor lo.

Import Template ke n8n

Template lo dalam bentuk file .json. Tinggal import.

  1. Buka n8n lo
  2. Klik tombol "..." (titik tiga) di pojok kanan atas
  3. Pilih "Import from File"
  4. Cari dan pilih file .json template
  5. Workflow langsung muncul di canvas
  6. Ulangi buat setiap template yang mau dipasang
Klik "..." kanan atas → Import from File → pilih file .json
Tips: Kalau file json-nya kebuka jadi teks panjang di browser, klik kanan file → Save As dulu, baru import.

Ganti Token & Nomor WA

Ini langkah paling penting. Semua template punya tulisan GANTI_... yang harus diganti.

Cara ganti

  1. Klik 2x kotak yang namanya ada tulisan "WhatsApp" atau "Kirim"
  2. Panel muncul di samping
  3. Scroll ke bawah sampai ketemu Send Headers
  4. Di kolom Value, ganti GANTI_TOKEN_FONNTE jadi token lo
  5. Scroll dikit lagi ke Send Body
  6. Ganti GANTI_NOMOR_WA_ADMIN jadi nomor WA lo
  7. Klik di luar panel buat nyimpan
Panel node — 2 tempat yang harus diganti: token & nomor WA

Aktifin & Tes

Terakhir — nyalain dan pastiin jalan.

  1. Klik Save (pojok kanan atas)
  2. Klik tombol Inactive di kanan atas → jadi Active
  3. Tes: klik Execute Workflow (tombol play ▶)
  4. Cek HP lo — harusnya ada WhatsApp masuk
  5. Kalau masuk, selesai!

Cara cek gak ada yang ketinggalan

Tekan Ctrl + F di halaman n8n, ketik GANTI.

Kalau ada hasil = masih ada yang belum diganti. Kalau gak ada = beres.

Klik toggle Inactive → Active. Hijau = jalan.
