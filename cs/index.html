// Alur Kerja

Dari chat masuk sampai selesai

STEP 01
📨

Pesan Masuk

Gateway WhatsApp teruskan pesan ke webhook n8n. Sistem cek nomor pengirim — customer atau admin.

STEP 02
🔍

Cek Mode

Baca Google Sheets. Kalau mode ai → lanjut ke AI. Kalau human → langsung teruskan ke admin.

STEP 03
🤖

AI Jawab

Prompt dikirim dengan 6 pesan terakhir sebagai konteks. AI balas singkat, maksimal 3 kalimat.

STEP 04
⚡

Deteksi Eskalasi

3 pemicu dicek. Kalau kena → mode jadi human, admin dapat notif lengkap, customer dapat pesan holding.

STEP 05
👤

Admin Balas

Admin tinggal reply notifikasi WA. Pesan otomatis diteruskan ke customer. Ketik "tutup" → balik ke AI.

STEP 06
⏰

Watchdog

Tiap 5 menit dicek. Admin lupa bales >10 menit → diingatkan. Customer tunggu >30 menit → dapat kabar.
