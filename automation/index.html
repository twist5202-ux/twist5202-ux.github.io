Rekomendasi: n8n Cloud (paling gampang) + Wablas (Rp 22rb/bulan, free trial 15 hari).

Cara termudah — n8n Cloud:

  1. Buka n8n.io → klik "Start free trial"
  2. Daftar pakai email lo
  3. Pilih region Singapore
  4. Selesai — langsung bisa dipakai

Cara termurah — VPS sendiri (jalan 24 jam):

Jalankan di server Ubuntu:

docker run -d --restart unless-stopped --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n

Lalu buka http://IP-SERVER-LO:5678

  1. Di n8n, klik ikon kunci (Credential) di panel kiri
  2. Klik Add Credential
  3. Pilih Google Sheets
  4. Klik Sign in with Google → pilih akun Gmail lo
  5. Klik Allow / Izinkan akses
  6. Klik Save

Credential ini cuma perlu sekali. Semua template bisa pakai credential yang sama.

Cara ambil ID Google Sheets: buka spreadsheet, liat URL — docs.google.com/spreadsheets/d/1AbCdEf.../edit. Yang tebal itu yang di-copy.
