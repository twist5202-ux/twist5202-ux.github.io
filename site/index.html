About

Twist — security researcher focused on web application penetration testing and vulnerability research.

Every finding in this portfolio was independently discovered, reproduced, and documented. Reports include proof of exploitation, the root cause located in the application code, and a fix. Findings that could not be confirmed are stated as unconfirmed rather than overstated.

All testing was performed against authorised training labs — primarily OWASP Juice Shop, an intentionally vulnerable application maintained by OWASP for exactly this purpose. No third-party system was tested without written permission.
