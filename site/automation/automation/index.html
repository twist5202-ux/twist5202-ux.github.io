Rekomendasi: n8n Cloud (paling gampang) + Wablas (Rp 22rb/bulan, free trial 15 hari).

Cara termudah — n8n Cloud:

  1. Buka n8n.io → klik "Start free trial"
  2. Daftar pakai email lo
  3. Pilih region Singapore
  4. Selesai — langsung bisa dipakai

Cara termurah — VPS sendiri (jalan 24 jam):

Jalankan di server Ubuntu:

docker run -d --restart unless-stopped --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n

Lalu buka http://IP-SERVER-LO:5678

  1. Di n8n, klik ikon kunci (Credential) di panel kiri
  2. Klik Add Credential
  3. Pilih Google Sheets
  4. Klik Sign in with Google → pilih akun Gmail lo
  5. Klik Allow / Izinkan akses
  6. Klik Save

Credential ini cuma perlu sekali. Semua template bisa pakai credential yang sama.

  7. Top up saldo (mulai Rp 50.000)

  2. Klik "..." (titik tiga) di pojok kanan atas
  3. Pilih "Import from File"

  6. Ulangi buat setiap template

  4. Scroll ke Send Body
  5. Ganti GANTI_NOMOR_WA_ADMIN jadi nomor WA lo

Cara ambil ID Google Sheets: buka spreadsheet, liat URL — docs.google.com/spreadsheets/d/1AbCdEf.../edit. Yang tebal itu yang di-copy.

  1. Klik Save (pojok kanan atas)
  2. Klik tombol Inactive → jadi Active

  4. Cek HP lo — harusnya ada WhatsApp masuk
  5. Kalau masuk, selesai!

FAQ

Masih ada pertanyaan?

Bisa. Gue yang setup semuanya. Lo tinggal pakai. Kalau ada yang perlu diubah (harga, alamat, nama toko), gue ajarin lewat training.
n8n itu aplikasi automation gratis. Gue yang install dan setup — bisa di komputer lo atau di server (VPS). Kalau mau yang paling simpel, gue setup di VPS biar jalan 24 jam tanpa perlu nyalain komputer.
Zapier bayar bulanan dan makin mahal kalau makin banyak. n8n sekali setup, gak ada biaya bulanan ke platform. Plus data lo tetap di server lo sendiri.
Mulai Rp 22rb/bulan (Wablas) atau bayar per saldo. Satu pesan sekitar Rp 150-300. Untuk UMKM kecil, realistis Rp 50-100rb/bulan.
Transfer bank, e-wallet (DANA/GoPay/OVO), atau USDC. Bisa DP 50% dulu, pelunasan setelah setup jalan.
Paket Premium dapat support 1 bulan penuh. Kalau ada masalah, chat aja — gue benerin gratis selama masa support.
